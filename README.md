# Portefølje i pedagogisk innovasjon og prototyping

Dette er en statisk nettside som kan åpnes i **Visual Studio Code** og publiseres med **GitHub Pages**.

## Starte lokalt

1. Pakk ut hele ZIP-filen til en prosjektmappe.
2. Åpne prosjektmappen i Visual Studio Code (`File` → `Open Folder`).
3. Høyreklikk `index.html` og velg **Open with Live Server** (hvis du har Live Server installert).
4. Test lenkene, POV-slideren, bildevisningen og personakortene.

Du kan også dobbeltklikke `index.html` for å åpne en enkel lokal forhåndsvisning.

## Filer

- `index.html`: alt innholdet og strukturen
- `styles.css`: typografi, farger og layout
- `script.js`: personas, bildevisning, A–D-slider og mobilmeny
- `images/`: de 35 originale PNG-filene

**Viktig:** Ikke endre navnene på bildefilene uten å oppdatere referansene i `index.html`.

## Publisering på GitHub Pages

Opprett et eget repository (ikke overskriv din første nettside). Last opp filene i prosjektets rot, og aktiver Pages fra `Settings` → `Pages` → `Deploy from a branch`, `main` / `(root)`.

## Innhold og videreutvikling

Første fungerende prototype med godkjente tekstformuleringer og valgt bildegalleri. Diagrammet over design thinking og de øvrige bildene er originale fra den opplastede bildemappen. Designet kan finjusteres videre, og eventuelle nye resultater fra brukertesting kan legges til senere.

De eksterne lenkene til Energiformer, Lærerlos, Algebrablomsten og den første nettsiden er tatt fra brukerens opplysninger. Kontroller at de fungerer før publisering.
